# Prompt Claude Design pour outils et interfaces

Lis config/economy.json. Crée une planche de tous les outils, puis les écrans de FILLING UP. Ne change ni leurs prix ni leurs effets. Pour les douze outils : vue trois-quarts, silhouette, icône lisible à 64 px, état équipé et détail du rang suivant. Un seul actif, un passif et un compagnon cosmétique sont équipables.

Priorité à la borne du Radar : le joueur vient de gagner 65 Coins ; le Radar coûte 50 ; l'achat laisse 15. Deux boutons : Acheter 50 Coins et Continuer. Aucun compte à rebours, aucune offre Robux automatique. Montrer l'effet sur trois appuis sans piloter l'avatar.

Écrans : HUD de salle sans chrono de défaite ; borne de premier achat ; inventaire ; boutique Coins ; boutique Robux ; aperçu 3D ; KO avec recommencement gratuit ; sauvegarde/reprise ; renaissance et confirmation. Ajouter les états chargement, erreur réseau, manque de Coins, possédé et indisponible. Les produits Robux du prototype sont des aperçus, pas de vrais paiements.

Pour la renaissance, afficher permis dépensés, rangs gagnés, bonus et retour à salle 1, puis ce qui est conservé : Coins, outils, améliorations, cosmétiques et achats. Le joueur peut continuer son expédition sans renaître.

Maquettes paysage 16:9 et écran compact. Contrôles tactiles d'au moins 44 points équivalents, zones de saut non recouvertes par la boutique. Police sans empattement lisible, textes courts en jeu. Prévoir l'anglais et le français sans figer des textes longs dans les icônes.

Les interfaces HTML éventuelles servent de référence. Fournis la hiérarchie, les tokens et les états pour reconstruction en UI Roblox native.
